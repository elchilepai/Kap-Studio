# Cómo usar este paquete

1. Para cada escena, abre `prompts/scene-NN.txt`, pégalo en tu generador de imágenes y **adjunta las referencias** de `referencias/` (KAP: `reference.jpg`; estilo: las otras). Usa el negative prompt si tu generador lo admite.
2. Guarda cada imagen como `imagenes/scene-NN.png` (mismo NN que la escena). Usa el MISMO generador, semilla/estilo y referencias en todas para mantener a KAP, al hermano y el mundo idénticos.
3. `narracion-elevenlabs.txt` es lo único que se debe locutar: las descripciones «Visual» NO se pronuncian.
4. Monta en CapCut: zoom, paneo, transiciones, música, subtítulos y efectos.

Imágenes esperadas: 5. Formato: 9:16.
