# Hooks

👉 **pregunta-incomoda**: ¿Cuántas veces cambias lo que dices… para gustarle a alguien?
- **situacion-reconocible**: Llevas veinte minutos mirando si te ha respondido.
- **afirmacion-inesperada**: Si haces esto, probablemente no estás buscando una respuesta.
- **error-comun**: Reescribir el mismo mensaje cinco veces no lo mejora: lo vuelve más importante de lo que es.
- **consecuencia**: Cada vez que borras ese mensaje, le das un poco más de poder a quien lo va a leer.
